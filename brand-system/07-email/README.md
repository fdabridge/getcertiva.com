# Email signature template

`signature.html` is an editable Certiva-only example. Replace the bracketed fields, verify the sender's title, phone and legal entity as appropriate, then paste into the mail client's signature editor. It has not been installed in any mailbox.

The HTML intentionally uses a text company name rather than a remote SVG image: many email clients block SVG or remote images. A separate `signature-preview.svg` shows the desired layout. If a raster logo is later hosted for email, test it in Gmail, Outlook desktop/mobile and dark mode before replacing the text name.

Keep the signature simple. Do not insert confidential implementation details, an accreditation mark, a certification stamp, or the founder's personal signature artwork.
